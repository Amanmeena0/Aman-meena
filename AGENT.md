# Portfolio Redesign Guidelines

## Project Vision

This project is a premium interactive developer portfolio.

The goal is NOT to build another template portfolio.

The goal is to create an unforgettable experience that feels cinematic, futuristic, and premium.

Every interaction should feel intentional.

Think Apple, Vercel, SpaceX, Linear, and Awwwards—not Bootstrap templates.

---

# Design Philosophy

Prioritize

- Simplicity
- Elegance
- Storytelling
- Motion
- Whitespace
- Smoothness

Avoid

- Generic gradients
- Generic cards
- Template layouts
- Random animations
- Excessive glow
- Overcrowded UI

Every section should have one clear purpose.

---

# Theme

The portfolio represents a digital universe.

The visitor is exploring my journey through space.

Sections become destinations.

Space is used as a storytelling metaphor—not as decoration.

# Mobile

Do not simply stack everything.

Create a unique mobile experience.

Simplify animations.

Maintain storytelling.

---

# Coding Rules

Always use TypeScript.

No any.

Use functional components.

Prefer composition.

Avoid prop drilling.

Keep components small.

No inline styles unless necessary.

---

# Styling Rules

Tailwind only.

Use CSS variables for colors.

Use utility classes.

No hardcoded spacing.

Maintain consistent border radius.

---

# Animations

Framer Motion first.

GSAP only for complex timelines.

Never mix animation libraries unnecessarily.

---

# Code Quality

Readable code.

Self-documenting names.

Reusable hooks.

Reusable UI components.

No magic numbers.

No duplicate logic.
